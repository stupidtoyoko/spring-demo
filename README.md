# Сервис управления аттракционами

## Тема проекта
Сервис для управления аттракционами в парке развлечений.  
Позволяет управлять расписанием аттракционов, посетителями и покупкой билетов с учётом ограничений.

---

## Основные сущности

- **Attraction (Аттракцион)** — описание аттракциона и его вместимость  
- **Schedule (Расписание)** — временные слоты для работы аттракционов  
- **Visitor (Посетитель)** — пользователь, покупающий билеты  
- **Ticket (Билет)** — бронирование места на конкретный слот  
- **Maintenance (Обслуживание)** — периоды, когда аттракцион недоступен  

---

## Возможности сервиса

### CRUD операции
- Создание, просмотр, обновление и удаление:
  - аттракционов
  - расписаний
  - посетителей
  - билетов
  - периодов обслуживания

---

### Бизнес-операции

-  **Покупка билета**
  - бронирование слота для посетителя
  - проверка вместимости аттракциона

-  **Ограничение вместимости**
  - нельзя купить билет, если свободных мест нет

-  **Учёт обслуживания**
  - покупка билета невозможна, если аттракцион на обслуживании

-  **Проверка доступности расписания**
  - определяет, можно ли купить билет на выбранный слот

---
