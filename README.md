# Парк аттракционов

## Описание
Сервис для управления парком аттракционов.

## Сущности
- Attraction — аттракционы
- Visitor — посетители
- Ticket — билеты
- Schedule — расписание
- Maintenance — обслуживание

## Возможности
- CRUD для всех сущностей
- Покупка билета
- Проверка вместимости
- Блокировка при обслуживании
- Поиск билетов и расписаний
